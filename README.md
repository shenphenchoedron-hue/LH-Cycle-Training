# LH Cycle Training

A free and open-source indoor cycling app for home trainers. It runs on Windows, macOS and Linux.

> **Status:** planning. No application code yet. See [PLAN.md](PLAN.md) for the full project plan.

## Planned features

- Ride real-world videos and GPX routes with smart trainers over Bluetooth (FTMS, Wahoo, Tacx), Wi-Fi Direct Connect, and serial (Daum/Kettler ergo bikes)
- Structured workouts (including Zwift `.zwo` files)
- A local video library: add videos from disk or a NAS, or use the optional local video server
- A video pairing wizard: combine a video with a GPX/FIT track, or import GoPro videos with built-in GPS, without editing XML files by hand
- Training history in SQLite with an analysis overview (fitness trend, power curve, zones, records)
- A new, colourful user interface
